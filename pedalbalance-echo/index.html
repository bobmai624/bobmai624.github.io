01 · THE PROBLEM

屏幕告诉你发生了什么，
身体却未必学会。

A screen can show the error
without teaching the body.

画面は誤差を示せても、
身体に学習させるとは限らない。

骑行者需要低头读取图表，再把视觉数字翻译成动作。PedalBalance Echo 把提示放回发生问题的一侧脚踝：左侧贡献持续偏低，就提示左侧；回到个人容差范围，就保持安静。

A rider must look down, read a chart and translate a visual number into movement. PedalBalance Echo returns the cue to the ankle where correction is needed: sustained lower left contribution cues the left; returning inside personal tolerance restores silence.

画面を見る方法では、数値を読み、それを動作へ翻訳する必要がある。PedalBalance Echo は修正が必要な側の足首へ手掛かりを返す。左の寄与が持続的に低ければ左へ提示し、個人の許容範囲へ戻れば沈黙する。

02 · MEASURE THE RIGHT THING

不要在错误的时间尺度上
比较两只脚。

Do not compare two feet
at the wrong time scale.

誤った時間尺度で
両足を比較しない。

踩踏本来就左右交替。瞬时比较会把正常相位差误报为不对称；系统必须等一个 complete revolution 结束后，再比较这一圈的相对压力贡献。

Pedalling naturally alternates left and right. Instantaneous comparison can misread normal phase difference as asymmetry; the system waits for one complete revolution before comparing relative pressure contribution.

ペダリングは左右が交互に働く。瞬間比較では正常な位相差を非対称と誤認し得るため、1回の complete revolution が終わってから相対圧力寄与を比較する。

03 · THE CORE LOOP

Human → Machine → Human

项目不是把人变成机器的被动执行器，而是让机器压缩身体数据，再把一个可以被身体直接理解的最小提示返还给人。

The project does not turn a person into a passive machine actuator. The machine compresses bodily data and returns the smallest cue the body can directly interpret.

人を機械の受動的な実行器にするのではない。機械が身体データを圧縮し、身体が直接理解できる最小限の手掛かりとして返す。

04 · ONE RIDING MOMENT

一次提示怎样发生？

What happens in one cue?

1回の提示はどう生まれるか。

  1. 01骑行者完成一圈踩踏。The rider completes one crank revolution.利用者がクランクを1回転させる。
  2. 02机器累计左右相对压力贡献。The machine accumulates bilateral relative pressure contribution.機械が左右の相対圧力寄与を積算する。
  3. 03短暂偏差被忽略；持续偏差才触发。Brief deviation is ignored; persistent error can trigger.一時的偏差は無視し、持続誤差のみを対象にする。
  4. 04贡献较低一侧的脚踝出现短振动。A short vibration appears at the lower-contributing ankle.寄与が低い側の足首へ短い振動を返す。
  5. 05人主动改变动作，机器不直接驱动肌肉。The person actively changes movement; the machine does not drive muscle.人が能動的に動きを変え、機械は筋肉を直接駆動しない。
  6. 06回到容差范围后提示消失。The cue disappears when performance returns inside tolerance.許容範囲へ戻ると提示は消える。

05 · TWO RESEARCH QUESTIONS

同一个身体闭环，检验两种学习关系。

One bodily loop, two learning relationships.

1つの身体ループで、2つの学習関係を検討する。

C1 · ASSISTANCE WITHDRAWAL

Adaptive feedback

持续振动、固定淡出和“只在持续错误时提示”的自适应反馈，哪一种更可能在提示关闭后仍留下修正能力？

Which condition—continuous haptics, fixed fade or persistent-error adaptive feedback—best supports correction after the cue is removed?

連続触覚、固定フェード、持続誤差に応じる適応提示のうち、提示撤去後の修正を最も支え得るのはどれか。

VISCHFFAF
Training → No feedback → 24 h retention → Transfer

E2 · BODILY TRACE REPLAY

Past-self replay

把自己过去表现最好的一段轨迹重新变成左右脚踝提示，和看屏幕、接收匹配他人轨迹或没有历史轨迹相比，会怎样改变动作？

What changes when a rider’s best past trace returns through the ankles rather than a screen, a matched-other trace or no history?

過去の自己ベスト軌跡を画面ではなく両足首へ返すと、他者軌跡や履歴なしの場合と比べて動作はどう変わるか。

This prototype does not build or operate DIY EMS/TENS/FES. FSR is only a complete-revolution relative pressure-contribution proxy—not power, torque, diagnosis or muscle strength.
