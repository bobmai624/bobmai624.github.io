THE WHOLE IDEA

先听完一整圈，
再给身体一个最小提示。

Listen for one full revolution,
then return one minimal bodily cue.

1回転を最後まで捉え、
身体へ最小限の提示を返す。

左右踏板记录这一圈的相对贡献。机器只在偏差持续时判断哪一侧需要帮助，再用短振动提示相应脚踝。骑行者自己修正下一圈；机器不替人发力。

The pedals record relative contribution across a complete revolution. Only a persistent deviation makes the machine choose a side and return a short ankle vibration. The rider corrects the next revolution; the machine never supplies the effort.

左右ペダルは1回転分の相対寄与を記録する。偏差が持続したときだけ機械が側を判断し、該当する足首へ短い振動を返す。次の1回転を修正するのは利用者自身であり、機械が力を代行することはない。

02HOW THE LOOP WORKS

HUMAN → MACHINE → HUMAN

四步完成一次闭环。

One closed loop in four steps.

4つの段階で閉ループをつくる。

这就是作品最重要的演示过程：数据从身体进入机器，经完整踏圈判断后，以最小提示返回身体。四步始终可见，不需要点击。

This is the project’s central demonstration: bodily data enters the machine, is interpreted across a complete revolution, and returns as a minimal cue. All four stages remain visible without a click.

これが本作の中心的な実演である。身体データが機械へ入り、1回転分を判断した後、最小限の提示として身体へ戻る。4段階はクリックせず常に確認できる。

01 · INPUTSENSEFSR-L + FSR-R · HALL

记录左右相对压力与每圈边界。

Record relative bilateral pressure and each revolution boundary.

左右の相対圧力と各回転の境界を記録する。

02 · INTERPRETDECIDECOMPLETE REVOLUTION

等一整圈结束，忽略短暂偏差。

Wait for the full revolution and ignore brief deviation.

1回転の終了を待ち、一時的な偏差を無視する。

03 · RETURNCUELEFT / SILENT / RIGHT

只向低贡献侧返回一次短振动。

Return one short vibration only to the lower-contributing side.

寄与が低い側だけへ短い振動を1回返す。

04 · LEARNCORRECTVOLUNTARY NEXT REV.

人主动调整下一圈，机器随后重新倾听。

The rider voluntarily adjusts the next revolution; the machine listens again.

利用者が次の1回転を能動的に調整し、機械は再び観測する。

WHY ONE COMPLETE REVOLUTION?

踩踏本来就左右交替。逐帧比较会把正常相位差误报为不对称；完整踏圈累计后，左右贡献才具有可比性。

Pedalling naturally alternates sides. Frame-by-frame comparison can misread normal phase difference as asymmetry; accumulated contributions become comparable only after a complete revolution.

ペダリングは左右が交互に働く。フレーム単位の比較は正常な位相差を非対称と誤認し得るため、1回転分を積算して初めて左右を比較できる。

03ONE REVOLUTION, THREE MOMENTS

THE DEMONSTRATION

一次提示，到底怎样发生？

How does one cue actually happen?

1回の提示は、実際にどう生まれるのか。

  1. LR
    00–360°

    自然踩完一圈

    Pedal one natural revolution

    自然に1回転する

    系统先收集完整一圈，不在左右交替的瞬间做结论。

    The system gathers the full revolution before judging alternating sides.

    左右が交互に働く瞬間には判断せず、1回転全体を収集する。

  2. 48:52
    AFTER 360°

    机器等待并判断

    The machine waits and decides

    機械が待って判断する

    若偏差超过个人容差且持续出现，才选择需要提示的一侧。

    Only a deviation beyond personal tolerance that persists selects a cue side.

    個人許容範囲を超える偏差が持続した場合だけ、提示側を選ぶ。

  3. SHORT CUE
    NEXT REVOLUTION

    身体修正下一圈

    The body corrects the next revolution

    身体が次の1回転を修正する

    对应脚踝收到短提示；人主动调整，回到容差后提示消失。

    The matching ankle receives a short cue; the rider adjusts and silence returns in tolerance.

    該当する足首が短い提示を受け、利用者が調整し、許容範囲へ戻ると沈黙する。

IMPORTANT这是一段“人 → 机器 → 人”的可操作演示，不是已完成的人体实验结果，也不代表机器直接驱动肌肉。This is an operable Human → Machine → Human demonstration—not a completed human-study result and not direct machine-driven muscle actuation.これは「人 → 機械 → 人」を操作できる形で示す実演であり、完了済みの人体実験結果でも、機械による筋肉の直接駆動でもない。

04HOW IT WAS BUILT

BUILD JOURNAL

三个模块，沿一条可检查的数据链工作。

Three modules work along one inspectable data chain.

3つのモジュールが、検証可能な1本のデータ連鎖で働く。

制作重点不是把零件装在一起，而是让“输入是否可信、每圈是否被正确切分、输出是否能安全清零”逐级可验证。

Making is not just assembly. Each level must show whether the input is repeatable, revolutions are segmented correctly and output can be safely cleared.

制作は部品の組み立てだけではない。入力の再現性、回転分割の正確さ、出力の安全な解除を段階ごとに検証できるようにする。

MODULE 01

踏板感知

Pedal sensing

ペダル感知

左右 FSR 读取相对压力趋势；Hall 传感器标记每一圈的开始与结束。

Bilateral FSRs read relative pressure trends; a Hall sensor marks each revolution boundary.

左右FSRが相対圧力傾向を読み、Hallセンサーが各回転の境界を示す。

MODULE 02

机器解释

Machine interpretation

機械による解釈

微控制器累计一整圈、与个人基线比较，并过滤一次性的偏差。

The controller accumulates a full revolution, compares personal baseline and filters one-off deviations.

コントローラが1回転分を積算し、個人基準と比較して一過性の偏差を除外する。

MODULE 03

脚踝返回

Ankle return

足首への返却

两侧振动马达只发送短提示；停止键与超时机制把输出恢复为零。

Two vibration motors send only short cues; stop and timeout logic restore output to zero.

左右の振動モータは短い提示だけを送り、停止・タイムアウト処理で出力をゼロへ戻す。

GATE A重复踩压产生方向一致的相对响应Repeated pressure produces directionally consistent relative response反復圧力で方向が一致する相対応答を得る

GATE B每一整圈只产生一个 Hall 事件One Hall boundary event is recorded per complete revolution1回転につきHall境界イベントを1回だけ記録する

GATE C停止、断连或超时会把所有输出清零Stop, disconnect or timeout clears every output停止・切断・タイムアウト時に全出力を解除する

05WHAT THE PARTICIPANT EXPERIENCES

STUDY JOURNEY

提示只是中段，
真正的问题在提示消失之后。

The cue is only the middle.
The real question begins after it disappears.

提示は中間段階にすぎない。
本当の問いは、提示が消えた後に始まる。

同一个人在相同任务节奏下经历五个阶段。这样才能区分“当下被帮助得更好”和“没有帮助时真的学会了”。

The same participant moves through five stages at a consistent task rhythm. This separates being helped now from learning that survives without help.

同じ参加者が同じ課題リズムで5段階を経験する。これにより、その場で助けられた成績と、助けなしで残る学習を区別する。

Does persistent-error adaptive feedback preserve correction without cues better than continuous feedback or fixed fade?

持続誤差にだけ応答する適応提示は、連続提示や固定フェードよりも、提示なしでの修正を残せるか。

06WHAT COUNTS AS EVIDENCE

CLAIM LADDER

把“能运行、能帮助、能学会”分开证明。

Prove that it runs, helps and teaches as three different claims.

「動く・助ける・学習を残す」を別々の主張として検証する。

LEVEL 01 · PROTOTYPE机制能运行The mechanism runs仕組みが動作する

输入、整圈分段、判断、提示与停止均可重复。

Input, revolution segmentation, decision, cue and stop are repeatable.

入力、回転分割、判断、提示、停止を再現できる。

LEVEL 02 · PERFORMANCE提示改善当下表现Cues improve current performance提示が現在の成績を改善する

提示开启时，相对贡献误差下降且无明显提示追逐。

With cues on, relative-contribution error falls without obvious cue chasing.

提示中に相対寄与誤差が減り、明確な提示追従が生じない。

LEVEL 03 · LEARNING无提示时仍能保持Improvement remains without cues提示なしでも改善が残る

立即、24 小时与新节奏测试仍显示改善，才接近学习证据。

Only immediate, 24-hour and changed-cadence tests can approach evidence of learning.

直後、24時間後、異なるケイデンスで改善が残って初めて、学習の証拠に近づく。

CURRENT STATUSILLUSTRATIVE SIMULATION + PLANNED STUDY

当前页面展示可操作机制与研究设计，不把模拟曲线写成参与者结果。FSR 只表示完整踏圈内的相对压力趋势，不是功率、扭矩、肌力或医学诊断。

The current page shows an operable mechanism and study design; simulated traces are not reported as participant results. FSR represents only relative pressure trends within a complete revolution—not power, torque, muscle strength or diagnosis.

現在のページは操作可能な仕組みと研究計画を示すもので、模擬軌跡を参加者結果として扱わない。FSRが示すのは1回転内の相対圧力傾向だけであり、パワー、トルク、筋力、診断ではない。

SAFETY TRANSLATIONVIBRATION OUTPUT · OPTIONAL READ-ONLY EMG · STATIONARY INDOOR PEDALLING · NO DIY EMS

本原型借鉴 EMS 研究中“何时介入、何时撤除帮助”的机制，但不制作或操作 DIY EMS/TENS/FES。紧急停止、超时清零和静态室内使用是设计边界。

The prototype learns when to intervene and withdraw assistance from EMS research, but does not build or operate DIY EMS/TENS/FES. Emergency stop, timeout clearing and stationary indoor use are design boundaries.

本プロトタイプはEMS研究から介入と支援撤去のタイミングを学ぶが、DIY EMS/TENS/FESは制作・操作しない。緊急停止、タイムアウト解除、屋内固定使用を設計境界とする。
